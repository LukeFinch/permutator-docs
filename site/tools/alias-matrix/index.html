Alias Matrix

Accent tokens that can be any hue, switched by mode.

Each colour keyword becomes a mode and each ramp keyword becomes a variable aliasing prefix/<colour>/<ramp>. A preview grid flags any source variable that is missing.

Why it helpsOne set of accent tokens covers every hue, so components don't need a variant per colour.
